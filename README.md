การเขียนโปรแกรมคอมพิวเตอร์สำหรับคณิตศาสตร์ (Computer Programming for Mathematics) มุ่งเน้นการศึกษาหลักการเขียนโปรแกรมพื้นฐาน การใช้ภาษาคอมพิวเตอร์เพื่อแก้ปัญหาทางคณิตศาสตร์ การคำนวณเชิงตัวเลข การสร้างอัลกอริทึม และการแสดงผลลัพธ์เป็นภาพกราฟิก เพื่อประยุกต์ใช้ในการวิเคราะห์ข้อมูลและสร้างแบบจำลองทางคณิตศาสตร์
